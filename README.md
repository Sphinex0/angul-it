# Angul-it

Small Angular demo showcasing CAPTCHA UI patterns (image grid, slider, text input).

Quick start

- Requirements: Node.js and npm
- Install: `npm install`
- Run (dev): `npm start` or `ng serve`

Structure

- Source: `src/` — main app code
- Captcha features: `src/app/features/captcha/` (components and UI)

Notes

- Built with Angular. Intended as a small demo and learning project.

That's it — open the app at http://localhost:4200/ after starting the dev server.
